# Jupiter (app)
Frontend (`index.html`, `app.js`, `lib/`, `styles.css`) and backend (`server/`). Every account gets its own private library: songs, playlists, favourites, listening stats and offline downloads. Nothing is shared between users.

Permissions (given to the `member` role at sign-up): `jupiter.library.read|write|delete`, `jupiter.stats.read`. `jupiter.admin.maintain` is admin only.

Privacy policy: `privacy.html`. Admin page: `admin.html` (admins only).
